# План: посев рынков карточек, проверенных в сети (слайс X)

Спека: `docs/superpowers/specs/2026-11-09-coin-card-market-seed-design.md`

## Шаг 1 — чистая функция поиска пар

- [x] `src/lib/coin-card-market-seed.ts`: `discoverCardMarkets(target,
      snapshots, anchors, now)` — ищет пары монеты в готовых снимках бирж,
      переводит котировку в доллар, сверяет с опорной ценой.
- [x] Охранник тикера-двойника: расхождение с опорой больше `PRICE_TOLERANCE`
      (25 %) — пара не берётся и попадает в `rejected`.
- [x] Охранник спора: биржа, не согласная с опорой ни одной парой, считается
      несогласной; если таких бирж не меньше, чем согласных, карточка не сеется
      и получает `reference_conflict`.
- [x] Опора старше `MAX_REFERENCE_AGE_MS` (48 ч) или отсутствующая →
      `no_reference`, посева нет.
- [x] Котировки — только стейблы (`SEED_QUOTES`): крипто-котировку мы от себя
      не заводим.
- [x] Лимит `MAX_SEEDED_MARKETS` (16) режет хвост по объёму, не голову.

## Шаг 2 — тесты чистой функции

- [x] `tests/coin-card-market-seed.test.ts`: пара со стейблом; тикер-двойник с
      мёртвым объёмом; спор о цене; мёртвая котировка на согласной бирже
      карточку не роняет; граница допуска в обе стороны; нет опоры; опора
      устарела; крипто-котировка не сеется; недоступная биржа; сортировка по
      объёму и лимит.

## Шаг 3 — прогон по базе

- [x] `seedCardMarkets({prisma, snapshots, anchors, cardId?, dryRun?})`:
      выбирает карточки по `seedWhere()` (открытые, без куратора и компании, с
      ключом сети, без ни одного рынка), берёт опорную цену из последнего
      `CoinSnapshot` монеты, пишет `CoinCardMarket` **без цены**
      (`skipDuplicates`), отдаёт статистику и план по каждой карточке.
- [x] Тесты на фальшивой призме: запись без цены; `--dump` не пишет; счётчики
      `no_reference` / `no_pairs` раздельны.

## Шаг 5 — воркер

- [x] `worker/index.ts`: `runCardMarketSeedJob()` на `40 4 * * *`, сразу после
      конвейера листинга (`25 4`); после удачного посева зовёт
      `runCardMarketSync()`, иначе новый рынок простоял бы без цены до
      следующего десятиминутного прогона.

## Шаг 6 — живой прогон

- [x] `--dump` по 36 карточкам: видно, где пары есть, где опора молчит, где
      источники спорят.
- [x] Первый настоящий прогон вскрыл дефект правила: спор считался по объёму, и
      застрявшая `BUSD`-пара (`POLYX/BUSD` — цена вчетверо выше стейбл-пар,
      объём 548 тыс.) убивала карточку с четырьмя здоровыми рынками. Правило
      переписано на биржи, крипто-котировки убраны из посева, рынки и индексы
      посеянных карточек удалены и заведены заново.
- [x] Проверка глазами: цена карточки сошлась с ценой монеты, комиссия перевода
      показана в долларах.
