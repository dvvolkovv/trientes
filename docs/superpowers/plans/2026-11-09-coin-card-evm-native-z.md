# План: нативные монеты EVM в карточках (слайс Z)

Спека: `docs/superpowers/specs/2026-11-09-coin-card-evm-native-design.md`.

## Шаги

1. **Реестр** — `src/lib/evm-chains.ts`: у `EvmChain` появляются `chainId`,
   `genesisHash?`, `symbol`, `decimals`, `transferGas`; добавляются десять новых
   сетей и их алиасы. Тест: ключи и chainId уникальны, у каждой сети 18 знаков,
   генезис — 64 hex, алиас ведёт к своей сети.
2. **Ридер** — `src/lib/evm-chain-read.ts`: `readEvmChainId`, `readEvmBlock`
   (`latest`/`finalized`/номер), `measureEvmBlockSeconds`, `readEvmGasPrice`,
   `transferFeeWei`. Отставание приводится к неотрицательному. Тесты на
   поддельном узле: нормальное чтение, отсутствующий блок 0, тег `finalized` без
   ответа, отрицательное отставание, заглавный хэш.
3. **Факты сети** — ветка `readEvmChainFacts` в `coin-card-chain-facts.ts`:
   `family: "EVM"`, `chainId` строкой, жёсткий `genesis_mismatch` при
   несовпадении chainId и при несовпадении генезиса, комиссия = цена газа ×
   `transferGas`.
4. **Порог финализации в секундах** — `FINALITY_SECONDS_MAX = 7200` вместо
   `FINALITY_LAG_MAX`; обновить тесты Astar (16,4 ч — отрезается) и проверить,
   что Mantle (24 мин) проходит.
5. **Выпуск** — ветка `EVM_NATIVE_V1` / `supply_unsupported` рядом с
   `BITCOIN_V1`.
6. **Семья в посеве и конвейере** — `chainFamily`, `coinFromRegistry`,
   `--family=EVM`, четырнадцать строк `SEED_CARDS`.
7. **Рендер** — «в том же блоке» по значению, а не по семье; подпись комиссии
   EVM (новый ключ в десяти локалях); метка сети из четвёртого реестра.
8. **Живой прогон** — посев, чтение, `--dump`, публикация сошедшихся, затем
   посев рынков слайса X.
9. **Сдача** — `npm test`, `tsc`, `build`, рестарт web+worker, `pm2 save`,
   коммит, пуш, CLAUDE.md.

## Риски

- **Нативная монета L2 — тот же ETH.** Привязка карточки ETH к Arbitrum дала бы
  «время блока 0,25 с» для монеты Ethereum. Защита: сеть попадает в посев только
  строкой кода, и в посеве её нет.
- **Публичный узел вернёт 403/429.** Два уже вернули (bsc, base); адрес
  переопределяется `EVM_RPC_<KEY>`, карточка при сбое сохраняет прошлые числа.
- **Смена семантики порога финализации** затрагивает Substrate и Cosmos.
  Проверяется тестами слайса V: Astar остаётся отрезанным, Cosmos — нулевым.
