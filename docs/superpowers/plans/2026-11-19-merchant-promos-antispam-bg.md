# План: акции магазина и рассылки с антиспамом (слайс BG)

Спека: `docs/superpowers/specs/2026-11-19-merchant-promos-antispam-design.md`.

## Порядок работы

1. **Схема и миграция** `20261119200000_merchant_promos`: `CompanyFollow`,
   `MerchantPromo`, `PromoSend`, `PromoDelivery`, `PromoClick`, `User.notifyPromos`.
   Миграция пишется руками и применяется `migrate deploy` (чекаут — прод).
2. **Чистые правила** `src/lib/promos/rules.ts`: разбор и проверка полей акции
   (заголовок, текст без URL, срок), `promoVisible`, окно показа.
   `src/lib/promos/antispam.ts`: `companyQuotaLeft`, `recipientAllowed`,
   `plannedDeliveries` — всё без Prisma, под тест.
3. **Чтение** `src/lib/promos/read.ts`: акции предприятия для витрины и кабинета, акция
   по товару, акции по точкам (для фида карточки точки), подписки человека, числа
   отправки.
4. **Действия** `src/app/actions/promos.ts` (создать, править, архивировать, разослать),
   `src/app/actions/company-follow.ts` (следить, отписаться, «не писать мне»),
   правка общего выключателя в существующем экшене настроек.
5. **Право `promos`** в `TEAM_SECTIONS`, шаблон «маркетолог» → `promos: EDIT`,
   журнал: `PROMO_CREATED`, `PROMO_UPDATED`, `PROMO_ARCHIVED`, `PROMO_SENT`.
6. **Экраны**: кабинет мерчанта `/promos`, раздел «Акции» и кнопка «Следить» на витрине,
   строка акции на странице товара, строка в карточке точки, раздел «Подписки» в
   кабинете покупателя, `/{locale}/promo/[id]` со счётом перехода.
7. **Переводы**: новые ключи в `messages/en.json` + `npm run i18n`.
8. **Тесты**: правила акции, антиспам (три потолка и три отключения), видимость,
   полнота шаблонов ролей и подписей журнала.
9. **Живой прогон на проде** временными записями: подписка, лимиты, рассылка во все
   каналы, переход, отписка; убрать за собой.
10. **Выкладка**: `npm run build`, `pm2 restart trientes-web` (воркер не трогаем — новых
    прогонов нет), `pm2 save`, коммит и push, запись в CLAUDE.md.

## Чего в плане нет

Гео-рассылки и гео-баннера (нет фоновой геолокации и координат людей), платных слотов
(нет платежей), сегментов по покупкам (нет покупок), жалобы на акцию как дела
комплайнса (ни одной живой рассылки).
