# OpenStreetMap как основа навигатора: базовая карта и пошаговые подсказки

Дата: 2026-11-14. Слайсы AG (базовая карта) и AH (манёвры и голос).

## Зачем

Владелец попросил взять `openstreetmap.org` за основу карты проекта.

Половина этого уже сделана и просто не подписана: адреса ищет Nominatim
(`nominatim.openstreetmap.org`), маршруты пешком и на машине считает OSRM на
серверах FOSSGIS (`routing.openstreetmap.de` — те же машины, что отвечают
кнопке «Directions» на самом osm.org), общественный транспорт — Transitous
MOTIS. Живое ведение (GPS-слежение, остаток пути, ETA, сход с маршрута,
прибытие, wake-lock) живёт в `navigation-controller.ts`.

Не сделано два куска:

1. **Базовая карта не OSM на вид.** Рисует её тёмный векторный стиль
   OpenFreeMap. Данные те же (OSM), но вид не тот, что на osm.org.
2. **Навигация без манёвров.** Запрос к OSRM идёт без `steps=true`, поэтому
   на карте есть линия, расстояние и время, но нет ни «через 200 м направо»,
   ни голоса.

## Слайс AG — базовая карта

**Решение:** базовый слой «Карта» — настоящие растровые тайлы
`https://tile.openstreetmap.org/{z}/{x}/{y}.png`, запрашиваемые **браузером
посетителя напрямую**, без нашего прокси.

Почему напрямую, а не через кэш nginx, как обсуждалось вслух: прокси сводит
все тайлы сайта к одному IP и снимает с запросов признак обычного посетителя
(Referer страницы, распределение по адресам) — для фонда это выглядит ровно
как то самое «тяжёлое использование», которое правила запрещают, и блокируют
такое в первую очередь. Прямые запросы из браузеров — обычный для сайта
способ, и кэш-заголовки тайлов браузер соблюдает сам.

**Риск назван вслух:** `tile.openstreetmap.org` — бесплатный сервер фонда
OSM. Правила разрешают только небольшую нагрузку, гарантий нет, отрезать
могут без предупреждения. Поэтому откат должен быть одной строкой.

**Как устроен откат.** Новый модуль `src/lib/basemap.ts` держит два пресета и
одну константу выбора:

- `osm` — растр `tile.openstreetmap.org`, атрибуция `© OpenStreetMap contributors`;
- `openfreemap` — прежний векторный стиль `tiles.openfreemap.org/styles/liberty`,
  атрибуция добавляет `© OpenFreeMap`.

Экспортируется `BASEMAP_STYLE` (готовый `StyleSpecification` или URL стиля) и
`BASEMAP_ATTRIBUTION` (строка для фиксированной атрибуции). Смена пресета —
правка одного значения.

**Что меняется в коде:**

- `crypto-navigator.tsx` — `BASE_STYLE_URL` уходит, `style: BASEMAP_STYLE`.
  Грефт спутника, рельефа, POI и маршрута работает как раньше: слои
  добавляются поверх базового, у растрового стиля базовый слой ровно один.
- `point-form.tsx` (мини-карта формы точки) — тот же `BASEMAP_STYLE`.
- `maplibre-attribution.ts` — фиксированная строка собирается из
  `BASEMAP_ATTRIBUTION` + `© Esri, Maxar, Earthstar Geographics` (спутник).
  Правило «атрибуция удалённого стиля — недоверенный HTML, показываем только
  свой фиксированный текст» остаётся.
- Тип `Base` переименования не требует: значение `"dark"` становится
  неправдой по смыслу, поэтому переименовывается в `"map"` (подпись в
  интерфейсе — существующий ключ `cryptoMap.streets`).

**Чего сознательно не делаем:** тёмной версии карты (osm.org светлая — именно
её и просили), своего тайл-сервера, прокси.

**Граница:** e2e-тест атрибуции (`tests/e2e/maplibre-attribution.spec.ts`)
требует текущую строку — он правится вместе с пресетом; плюс юнит-тест на то,
что активный пресет и строка атрибуции сходятся (нельзя показать OSM-тайлы с
подписью OpenFreeMap и наоборот).

## Слайс AH — пошаговые манёвры и голос

**Данные.** Запрос к OSRM получает `steps=true`. `parseOsrm` начинает
возвращать `steps: RouteStep[]`:

```ts
type RouteStep = {
  type: string;            // maneuver.type: turn | depart | arrive | roundabout | …
  modifier: string | null; // left | right | slight left | sharp right | straight | uturn
  name: string | null;     // улица, пустая строка → null
  distance: number;        // длина шага, метры
  exit: number | null;     // съезд с круга
  location: [number, number];
};
```

Шаги склеиваются из всех `legs`. Маршрут без шагов (старый кэш в Redis,
ответ без `steps`) остаётся валидным — поле необязательное, интерфейс просто
не показывает список. Ключ кэша маршрутов не меняется: запись живёт час, и
день со списком шагов у части пользователей — не дефект.

Транспортный режим (MOTIS) манёвров не получает: там уже есть свой разбор на
ноги маршрута.

**Чистый модуль `src/lib/route-steps.ts`** (без DOM, тестируется юнитами):

- `cumulativeEnds(steps): number[]` — расстояние от старта до конца каждого шага;
- `activeStep(travelledMeters, ends): { index, distanceToManeuver }` — какой шаг
  идёт сейчас и сколько до следующего манёвра (манёвр стоит в начале шага,
  значит до конца текущего);
- `announcementBand(distance, mode): "far" | "near" | "now" | null` — пороги
  озвучки: машина 400 / 150 / 30 м, пешком 120 / 50 / 15 м.

Пройденное расстояние берётся как `route.distance - remaining`, где
`remaining` уже считает `remainingMeters` в контроллере навигации.

**Контроллер.** `NavigationController` получает `setSteps(steps, totalDistance)`
и новый колбэк `onStep(index, distanceToManeuver)`. Решение «что сказать» и
«не повторяться» принимает компонент: контроллер остаётся датчиком, а не
диктором.

**Текст манёвра.** Собирается из двух частей, чтобы не плодить комбинации:
фраза манёвра (`cryptoMap.nav.turnLeft` = «Поверните налево») плюс, если у
шага есть улица, `cryptoMap.nav.onto` = «на {name}». Для голоса добавляется
`cryptoMap.nav.inDistance` = «Через {distance}, {instruction}». Неизвестный
тип манёвра падает на `cryptoMap.nav.continue` — молчание хуже обобщения.

**Интерфейс.**

- В панели маршрута под расстоянием и временем — список шагов: стрелка
  манёвра, текст, длина шага. Список сворачиваемый, по умолчанию свёрнут.
- Во время ведения — баннер текущего манёвра над картой: стрелка, текст,
  расстояние до манёвра, считается живым GPS.
- Кнопка звука рядом с «Вести»: 🔊/🔇, состояние в `localStorage`
  (`cmap:voice`), по умолчанию **включено**.

**Голос.** `window.speechSynthesis`, язык реплики — локаль страницы. Нет
поддержки в браузере — кнопка не показывается, баннер и список остаются.
Каждая полоса (`far`/`near`/`now`) произносится один раз на шаг; смена шага
сбрасывает сказанное. Прибытие произносится один раз.

**Границы (юнит-тесты):**

- `parseOsrm` достаёт шаги из нескольких ног и переживает ответ без `steps`;
- `cumulativeEnds` / `activeStep` на синтетическом маршруте: позиция в
  середине шага, точно на границе, за концом маршрута;
- `announcementBand` — каждая полоса и тишина между ними;
- сборка текста манёвра: с улицей и без, круг с номером съезда, неизвестный
  тип → «продолжайте движение».

## Что не входит

Офлайн-карты, голос через наш TTS (браузерный синтез бесплатен и не ходит на
сервер), перестроение маршрута при сходе с него (сейчас только
предупреждение — отдельный слайс), манёвры для общественного транспорта.
