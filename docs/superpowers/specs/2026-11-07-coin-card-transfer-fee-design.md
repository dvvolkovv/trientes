# Проверенная комиссия перевода (слайс T)

**Дата:** 2026-11-07
**Разделы:** публичная карточка `/{locale}/coin/[slug]` (секции `#acceptance`,
блок «Сеть монеты»); воркер (часовой прогон фактов сети)

## Контекст

Слайс S сознательно оставил комиссию перевода за границей: «для неё нужно
кодировать экстринсик по метаданным рантайма». Поэтому сейчас в платёжном
профиле карточки комиссия — единственное число, которое остаётся
самозаявлением проекта (`payments.feeUsdTypical`, метка `SELF_REPORTED`), тогда
как время блока и финальность уже проверены.

Для продавца это худшее из возможных распределений доверия: скорость, которую
он проверить не может, проверена, а комиссия, которую он платит с каждого
платежа, — нет.

Оказалось, что полный декодер метаданных не нужен. Узел сам считает комиссию
(`payment_queryInfo`, `payment_queryFeeDetails`) — ему нужен только собранный
экстринсик. Проверено живыми запросами 7 ноября 2026:

| Сеть | Балансы | Комиссия перевода (узел) | Из чего сложилась |
| ---- | ------- | ------------------------ | ----------------- |
| Taler (`specVersion` 12, `transactionVersion` 2) | палета **6** | `2 633 280` планка = **0,0000026 TAL** | база `2 488 280` + длина `145 000` + вес `0` |
| Polkadot (`2005002`, txv **26**) | палета **5** | `159 206 918` = **0,0159 DOT** | база `10 000 000` + длина `145 998 976` + вес `3 207 430` |
| Kusama (`2005001`, txv **26**) | палета **4** | `533 248 407` = **0,000533 KSM** | база `33 234 005` + длина `486 538 180` + вес `13 248 382` |

Два факта из этих же прогонов определяют конструкцию:

1. **Неподписанный экстринсик бесплатен.** Для неподписанного
   `Balances.transfer_keep_alive` узел отвечает `partialFee: "0"` — комиссию
   платит подписант, которого в неподписанном экстринсике нет. Значит собирать
   надо подписанный, с подписью-пустышкой: узел при расчёте комиссии подпись не
   проверяет, но длину байтов учитывает.
2. **Набор подписанных расширений у сетей разный.** У Polkadot и Kusama есть
   `CheckMetadataHash` — ровно один лишний байт режима в конце; у Taler его нет.
   Экстринсик с лишним байтом не декодируется вообще
   (`Unable to query dispatch info.`), поэтому вариант определяется попыткой, а
   не записывается в реестр.

## Принципы

Слайс наследует правила S и добавляет одно.

1. **Считает узел, а не мы.** Комиссия не собирается в коде из базы, длины и
   веса: формула живёт в рантайме сети (полином `WeightToFee`, множитель
   `NextFeeMultiplier`) и меняется без предупреждения. Мы собираем экстринсик и
   спрашиваем цену у сети.
2. **Номер палеты пришпилен и охраняется версией транзакций.** Индекс палеты
   балансов в метаданных есть, но добраться до него — это декодер реестра типов
   метаданных V14/V15 (несколько сотен строк). Вместо него — проверенный живьём
   индекс в реестре сетей плюс `transactionVersion`, которую сеть бампает
   именно при смене формата экстринсика и индексов вызовов. Разошлась версия →
   комиссия становится неизвестной (`runtime_changed`), а не показывается
   устаревшей.
3. **Неизвестное молчит.** Нет комиссии — блок не рисует ноль и не подставляет
   заявление проекта вместо факта. Ноль у комиссии — допустимое значение (бывают
   сети без комиссии), поэтому «нет данных» и «ноль» различаются типом, а не
   магическим числом.
4. **Эталонный перевод один и тот же.** Комиссия зависит от длины экстринсика,
   то есть от суммы перевода (компактная кодировка) и от способа вызова.
   Эталон фиксирован: `transfer_keep_alive` одной целой монеты на обычный
   адрес, бессмертная эра, нонс 0, без чаевых. На карточке подписано именно так
   — «перевод одной монеты», а не «типичная комиссия».
5. **Заявление проекта не правится** (правило S). Факт — в `CoinCardChainFacts`;
   расхождение с `payments.feeUsdTypical` попадает в `mismatches` и видно рядом.

## Данные

Комиссия — такой же факт сети, как время блока, и читается тем же прогоном,
поэтому новой модели нет: три поля в `CoinCardChainFacts`.

```prisma
model CoinCardChainFacts {
  // ...
  /// Комиссия эталонного перевода в наименьших единицах. String, а не BigInt:
  /// значение приходит из RPC строкой и дальше только форматируется.
  transferFeePlanck String?
  /// Та же комиссия в монетах: planck / 10^tokenDecimals. Float — для рендера.
  transferFeeTokens Float?
  /// fee_unsupported | runtime_changed | rpc_error | decode_failed
  transferFeeError  String?
}
```

Комиссия в USD **не хранится**: она равна `transferFeeTokens × priceUsd`, а
цена обновляется каждые десять минут — хранить произведение значило бы хранить
заведомо устаревшее число. Рендер считает его из `CoinCardPriceIndex`, если
индекс есть; у монеты без рынков (сегодня это Taler) показывается только
комиссия в монетах.

Реестр сетей получает два пришпиленных поля:

```ts
export type SubstrateChain = {
  // ...
  /// Индекс палеты балансов в рантайме. Проверен живым запросом; охраняется
  /// transactionVersion.
  balancesPallet: number;
  /// Версия формата транзакций, при которой индекс проверен.
  transactionVersion: number;
};
```

Индекс вызова `transfer_keep_alive` — **3** во всех трёх сетях и во всех
версиях палеты балансов, которые существовали (и до переименования
`transfer` → `transfer_allow_death`, и после). Это константа кодека, а не поле
реестра.

## Что читаем

| Что | Запрос | Зачем |
| --- | ------ | ----- |
| версия транзакций | `state_getRuntimeVersion` | сверка с пришпиленной; расхождение → `runtime_changed` |
| комиссия | `payment_queryInfo(ext)` → `partialFee` | число, которое показываем |
| состав комиссии | `payment_queryFeeDetails(ext)` | только для теста и отладки, в базу не пишется |

## Поток

`syncChainFacts(cardId)` (слайс S) после замера времени блока:

1. Нет `balancesPallet` у сети → `transferFeeError = "fee_unsupported"`, выходим.
2. `state_getRuntimeVersion` → `transactionVersion ≠ chain.transactionVersion`
   → `transferFeeError = "runtime_changed"`, комиссия `null`.
3. Собираем экстринсик без байта режима, спрашиваем `payment_queryInfo`.
   Ошибка декодирования → повторяем с байтом режима. Снова ошибка →
   `transferFeeError = "decode_failed"`.
4. `partialFee` → `transferFeePlanck`; делим на `10^tokenDecimals` →
   `transferFeeTokens`.
5. Есть `CoinCardPriceIndex` и заявленная `payments.feeUsdTypical` → сравниваем.
   Расхождение считается значимым, когда оно больше **и** 10 %, **и** одного
   цента: у сети с комиссией в доли микроцента относительная разница шумит.
   Значимое расхождение → код `FEE_USD` в `mismatches`.
6. Провенанс: `payments.feeUsdTypical → VERIFIED_ONCHAIN` ставится только когда
   цена известна (иначе проверенного USD-числа у нас нет).

## Сборка экстринсика

Новый файл `src/lib/substrate-extrinsic.ts` — чистые функции, без сети:

```ts
compactEncode(n: bigint): Uint8Array        // SCALE compact
transferKeepAliveCall(args: { pallet: number; dest: Uint8Array; value: bigint }): Uint8Array
fakeSignedExtrinsic(args: { call: Uint8Array; signer: Uint8Array; metadataHashMode: boolean }): string
```

Подписанный экстринсик: версия `0x84` → `MultiAddress::Id` (`0x00` + 32 байта)
→ `MultiSignature::Sr25519` (`0x01` + 64 байта) → эра `0x00` → нонс `compact(0)`
→ чаевые `compact(0)` → при `metadataHashMode` байт `0x00` → вызов. Всё это
оборачивается компактной длиной. Подпись и подписант — байты-пустышки
(`0x22…`, `0x33…`): узел их не проверяет, а код никогда не подписывает
по-настоящему и не умеет отправлять экстринсики — `author_submitExtrinsic` в
проекте не вызывается нигде.

## Как это видно

- **Блок «Сеть монеты»** — строка «Комиссия перевода»: `0,0000026 TAL`
  (и `≈ $0,0001`, когда цена известна), подпись «перевод одной монеты, замер
  <дата>». Ошибка → строки нет вовсе.
- **Платёжный профиль** (`payments-block`) — строка комиссии предпочитает факт,
  как это уже сделано для времени блока; при расхождении рядом «проект
  заявляет: $0,01».
- **Переводы** на 10 локалей: `coin.network.transferFee`,
  `coin.network.transferFeeHint`, `coin.payments.feeClaimed`.

## Ошибки

| Код | Когда | Что видит человек |
| --- | ----- | ----------------- |
| `fee_unsupported` | у сети в реестре нет `balancesPallet` | строки комиссии нет |
| `runtime_changed` | `transactionVersion` сети ≠ пришпиленной | строки нет; в админском журнале факт расхождения |
| `decode_failed` | оба варианта экстринсика не декодировались | строки нет |
| `rpc_error` / `rpc_unreachable` | узел не ответил | строки нет; остальные факты сети сохраняются |

Ошибка комиссии **не роняет** остальные факты сети: прогон пишет время блока и
финальность, а в `transferFeeError` — причину.

  недоступный узел.
- `tests/coin-card-chain-facts.test.ts` — `runtime_changed` при расхождении
  версии; расхождение `FEE_USD` только когда оно больше и 10 %, и цента;
  комиссия в USD не считается без индекса цены.

## Границы

Не в этом слайсе: комиссия для токенов в чужих сетях (EVM-карточки), чаевые и
приоритет, прогноз множителя `NextFeeMultiplier`, комиссия перевода других
активов (`assets`, `tokens`), декодер метаданных рантайма, отправка
экстринсиков.
